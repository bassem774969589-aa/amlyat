# 📋 TaskFlow — أداة إدارة المهام والبيانات المحلية

أداة ويب خفيفة وسريعة لإدارة المهام اليومية، تنظيم البيانات، ومتابعة الأدوار الوظيفية داخل الفريق. تعمل بالكامل داخل المتصفح دون الحاجة إلى خادم خارجي، مما يجعلها مثالية للاستخدام الشخصي أو للفرق الصغيرة.

## ✨ المميزات

- 🔐 **نظام دخول آمن:** واجهة تسجيل دخول بسيطة تحمي البيانات من الوصول غير المصرح به.
- 👥 **إدارة المستخدمين والأدوار:** دعم دورين أساسيين (مدير النظام / مستخدم عادي) مع صلاحيات مختلفة لكل دور.
- 📊 **لوحة قيادة تفاعلية:** عرض إحصائيات سريعة ومؤشرات أداء في مكان واحد.
- 🗂️ **إدارة السجلات:** إضافة، تعديل، وعرض السجلات مع حقول متعددة قابلة للتخصيص.
- 📝 **تقارير يومية:** إنشاء تقارير نصية مرتبطة بفئات محددة ومراجعتها لاحقاً.
- 📈 **تحليل تلقائي للبيانات:** لوحة تقوم باحتساب مؤشرات تقديرية بناءً على البيانات المُدخلة وتنبّه المستخدم عند تجاوز حدود معينة.
- 📱 **مشاركة سريعة:** إرسال ملخصات السجلات عبر تطبيقات المراسلة المدعومة بضغطة زر.
- 🖨️ **تصدير وطباعة:** تقارير جاهزة للطباعة بتنسيق نظيف.
- 🌙 **واجهة داكنة مريحة للعين:** تصميم حديث يناسب الاستخدام الطويل.

## 🚀 طريقة التشغيل

### الطريقة الأولى: فتح الملف مباشرة
1. حمّل ملف `index.html`.
2. افتحه في أي متصفح حديث.
3. ابدأ الاستخدام فوراً.

### الطريقة الثانية: الاستضافة المجانية
1. ارفع الملفات إلى مستودع GitHub.
2. اذهب إلى **Settings** → **Pages**.
3. اختر الفرع `main` والمجلد `/ (root)`.
4. احفظ التغييرات، وستحصل على رابط مباشر بعد دقيقة.

## 🛠️ التقنيات المستخدمة

- **HTML5** — هيكل الصفحة.
- **Tailwind CSS** — تنسيق الواجهة.
- **FontAwesome** — الأيقونات.
- **JavaScript** — منطق التطبيق.
- **LocalStorage** — تخزين البيانات محلياً في المتصفح.
